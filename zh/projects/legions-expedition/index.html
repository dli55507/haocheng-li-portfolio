Legion’s Expedition

一款受自走棋启发的幸存者类游戏（“军团远征”）：组建军团、发掘小队羁绊，并在不断升级的压力下让队伍存活下去。

试玩在线版本 ↗ 观看演示视频 ↓

核心概念

统领小队，左右战局。

与传统幸存者类游戏不同，在 Legion’s Expedition 中玩家并非孤身作战，而是作为指挥官，率领一支自主作战的英雄小队。

玩家专注于战术走位、闪避和精准射击；招募来的单位则依靠各自专属的 AI 行为和独特技能，自行索敌、投入战斗。

随着敌潮一波比一波凶猛，玩家需要招募新单位、发掘强力组合，并将三个相同英雄合成为一个更强的版本，把一支杂牌小队打造成配合默契的战斗部队。

开发工具
Godot / GDScript
核心重点
小队战斗 / 程序化系统
数据采集
后端数据分析 API

招募系统

挑选角色，构建阵型。

招募、刷新、部署或锁定商店。每一个决定都会影响小队的前排、伤害构成、英雄羁绊以及之后的合成选择。

Boss 战

三个 Boss，各具攻击模式

每个 Boss 都有单独设计的攻击模式，考验玩家的走位、站位和小队搭配。

系统与功能

六大支柱

01

小队制幸存者战斗

游戏受《吸血鬼幸存者》和自走棋启发，将幸存者玩法从孤身作战转变为指挥一支不断壮大的自主英雄小队。

02

英雄、敌人与 Boss

六种以上的英雄设计为小队带来各不相同的能力，六种以上的小怪和三个 Boss 也各有独特的攻击模式。

03

三合一成长

三个相同英雄合成为一个更强的版本——这一经典的自走棋规则让小队不断变强，以应对愈发危险的敌潮。

04

程序化拼接地图

每一局都会按照布局规则重新组合地图图块和环境素材，让战场保持多样，同时不牺牲路线的可读性。

05

隐藏式自适应难度

受《生化危机》系列启发，后台的动态难度系统会随着对局进展调整压力。

06

实时玩家遥测

后端数据分析 API 实时采集存活时间、进度及其他游玩指标，为评估和设计迭代提供支持。

遥测与迭代

量化每一局，打磨整款游戏。

集成的数据分析 API 会将会话、进度和存活数据实时发送到 Talo。这些记录既用于课程报告，也让我们能够跨版本比较平衡性调整对玩家行为的影响。
