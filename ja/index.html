ゲーム・グラフィックス・ソフトウェアエンジニア

ワシントン大学（ポール・G・アレン・スクール）でコンピュータサイエンスの学位を取得し、現在は南カリフォルニア大学（USC）のコンピュータサイエンス修士課程（ゲーム開発）に進学したところです。

アイデアを形にし、誰かが実際に体験して心を動かされるものへと仕上げることが好きで、ゲームを作っています。ゲーム・グラフィックスエンジニアとして、レベルデザインやカメラワークからシミュレーション、リアルタイムレンダリングまで、ゲームの「手触り」と「見え方」の両方にこだわっています。

ゲーム開発には Unity、Unreal Engine、Godot を使用しています。そのほか、Java と Spring Boot による API 設計、AWS 上のクラウドインフラ、Hadoop と Spark による大規模データ処理、分散システム、機械学習など、幅広いエンジニアリングに取り組んできました。

この身、風のごとく（Light as Wind）

海を越え、はるか遠い空を目指す、幻想的なピクセルアートの横スクロールアドベンチャーです。3体のぬいぐるみの主人公を操作し、動きがすべてプロシージャルアニメーションで表現された海の生き物たちの間を進みます。

このプロジェクトでの主な担当（これらに限りません）：

  • レベル04・06・10のレベルデザイン
  • 各レベルのインタラクションメカニクスの設計、ゲームプレイのロジックとエフェクトの実装、QA とバグ修正
  • 遠近感のあるピクセルアートのための独自レンダーパイプラインと、スケルタルリグを使わない完全プロシージャルアニメーションが土台
  • リアルタイム物理とゲームフィール：風に舞う紙、メカジキの泳ぎ、カニのツタ渡り
  • シェーダーと破壊表現：Worley ノイズによる「空気の壁」と、ランタイムのメッシュ破砕
  • Unity 6
